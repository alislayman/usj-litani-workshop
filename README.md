# USJ workshop: Litani villages

The pages and tools of a 90-minute workshop held by Green Southerners with Université Saint-Joseph, November 2026:
four groups read the 2026 war in four villages of the lower Litani valley (Arnoun, Yohmor, Zawtar El Sharqiyeh and
El Gharbiyeh, Deir Siryan) on free Sentinel-2 pictures and public reports.

Open the site: https://alislayman.github.io/usj-litani-workshop/ (English) or https://alislayman.github.io/usj-litani-workshop/0-start-here-ar.html (Arabic).

* `index.html`, `0-start-here.html`: the four groups. `pages/`: each group's page, Tools, Links, Prerequisites, in
  English and Arabic (`-ar`).
* `change-marker/`: compare two pictures, mark what changed, export to Google Earth. Online it holds the tool alone:
  the village pictures are in each group's folder, shared on the workshop board.
* `tools/sheet-to-kmz.html`: turn a group's sheet into a KMZ. `sheet/`: the group sheet template.

Pictures in the tools: contains modified Copernicus Sentinel data. River line: OpenStreetMap contributors (ODbL).
